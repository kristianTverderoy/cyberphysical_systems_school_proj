Using msvc to build:
  - Make sure msvc compiler is downloaded via Visual Studio 
  - type into terminal (any should work) (must be at the root of the project also):
    - cmake --preset windows-msvc 
    - cmake --build --preset windows-msvc
  - exe file should then be in ./msvc-build/Release/window.exe

Using gcc to build:
  - Make sure gcc compiler is downloaded.
  - type into terminal (any should work) (must be at the root of the project also):
    - cmake --preset linux
    - cmake --build --preset linux
  - file should then be in ./build/window
